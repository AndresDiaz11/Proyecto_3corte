# Base de Datos de Fútbol ⚽

Este repositorio contiene una base de datos estructurada con información histórica de las ultimas 4 temporadas de las ligas europeas mas determinantes y sus estadísticas de fútbol, ideal para realizar análisis exploratorio de datos, cruces estadísticos o visualizaciones.

## 🗂️ Estructura de las Colecciones

El proyecto está dividido en tres colecciones principales que se relacionan entre sí:

* **`standings` (Tabla de Posiciones):** Clasificación del torneo. Incluye puntos acumulados, diferencia de goles, partidos ganados/empatados/perdidos y el rendimiento general de cada club.
* **`partidos` (Resultados):** Historial de los encuentros. Contiene las fechas, equipos locales vs. visitantes, marcadores finales y condiciones del partido.
* **`goleadores` (Rendimiento Individual):** Registro de los máximos anotadores del torneo. Detalla el nombre del jugador, cantidad de goles, equipo al que pertenece y promedio de anotación.
